# KN-83, SiLU

`Engine.Stage.Silu::run` is row 13's S8, the work of `silu` in
`crates/exact`, which the gated feed-forward applies to each gate value. A
value arrives as a signed 64-bit integer in units of 2^-16, two
little-endian words. Its exponent `|x| log2(e)` is taken in units of 2^-8,
rounded half to even (`LOG2_E` is the integer nearest `2^32 log2(e)`); its
weight `w` is KN-56's `exp2Neg` of that exponent; and the result is
`x 2^30 / (2^30 + w)` for `x >= 0`, or `x w / (2^30 + w)` below zero,
rounded half to even, both roundings by KN-81's `divideEven`. The Rust caps
the exponent at `u32::MAX` before the table; `exp2Neg` is already 0 long
before that, so the stage takes the exponent as it is, and the row includes
values past the cap.
